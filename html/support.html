Frequently asked questions

What platforms does BorgVR support?

BorgVR supports iPhone, iPad, Mac, and Apple Vision Pro. Available features can vary slightly by platform.

Can I open my own datasets?

Yes. BorgVR can open local datasets, import new data, and connect to configured remote dataset servers.

Does collaboration require all devices to have the same dataset?

BorgVR can synchronize the current dataset and rendering state. If needed, the host can make the current dataset available to participants.

Why does BorgVR ask for local network access?

Local network access is used for remote datasets, collaboration, and temporary dataset sharing between devices.
