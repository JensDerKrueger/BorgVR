User guide

Understand large volume data, not just display it.

BorgVR combines native Metal renderers, spatial interaction, SharePlay, dataset servers, and a WebGPU client. This guide takes you from the first dataset to collaborative analysis.

Start with the concepts Choose an application

One system, several entry points

The right tool for each workspace

All renderers use the same BorgVR datasets, transfer functions, and marker files, while each interface is adapted to its platform.

Prepare the data

Open existing BorgVR files, import DICOM, NRRD, PVM, or QVIS data, or obtain a dataset from a server.

Shape the visualization

Choose transfer-function, illuminated transfer-function, or isosurface rendering and adjust clipping, detail, and sampling.

Share the result

Save transfer functions and markers or collaborate with other people through SharePlay and WebGPU.
