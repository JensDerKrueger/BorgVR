Automate BorgVR with GSC

GSC scripts control the macOS renderer, import datasets, create reproducible views, and export image sequences. This page documents the language and every BorgVR command.

About Graphics Script

Graphics Script (GSC) is a line-oriented language for reproducible graphics workflows. BorgVR for macOS executes files with the .gsc extension. Open a script from the Script menu or drag it onto the BorgVR start screen.

A dedicated window shows log messages, errors, and long-running import progress while a script executes. BorgVR automatically waits for input dialogs, imports, screenshots, and loading commands before advancing.

Graphical editor The Graphics Script Editor provides syntax support and a graphical environment for creating GSC files.
Running scripts Language Examples Commands Objects and measurements

Run and record scripts

  1. Save the source as a UTF-8 file with the .gsc extension.
  2. Open it in BorgVR for macOS from the Script menu or by dragging it onto the start screen.
  3. Follow execution and errors in the script log. Cancelling an input dialog or encountering an invalid command stops the script.

Use Start recording and Stop and save to capture interactive changes as a GSC file. Consecutive transforms, clipping changes, and transfer-function edits are coalesced. The currently open dataset is saved as the first command.

Paths and output directory Absolute paths are used directly. Relative paths are resolved below the current script output directory selected with setdir. Put names containing spaces in single or double quotes.

Language basics

boolintint64floatdoublestringrestString
Commands
Each non-empty line contains one command followed by whitespace-separated arguments. Command names are case-sensitive.
Comments
Everything from # to the end of the line is a comment.
Strings
Single and double quotes group text containing spaces. Inside a quoted string, a backslash escapes the next character.
Boolean values
1/0, true/false, on/off, yes/no
Execution batches
A truly empty line ends an execution batch. This lets BorgVR complete a frame or asynchronous operation before the next batch starts. Comment-only lines do not create a batch boundary.

Variables and expressions

VariablesGSC
# A literal value
set steps 72

# Integer expressions support +, -, *, / and normal precedence
set degrees 360 / $steps

# $name and ${name} substitute variables inside any token
log "Rendering $steps frames at ${degrees} degrees"

# $$ produces a literal dollar sign
log "Cost: $$10"

unset degrees

set stores a single value, the result of an integer expression, or the return value of an input function. Integer expressions support +, -, *, and /; multiplication and division take precedence. Parentheses are not supported.

Loops and conditions

Control flowGSC
repeat 4 as index
  if $index == 0
    log "First pass"
  else
    log "Pass $index"
  endif
endrepeat

repeat count repeats the block through endrepeat. Add as name for a zero-based counter. if accepts a Boolean/integer value or a comparison. Numbers support == != < <= > >=; strings support == and !=. Blocks may be nested.

Interactive return values

Use input, fileinput, and dirinput on the right side of set. The interpreter waits for the dialog. Cancelling stops the entire script.

set title input "Dataset description"
set source fileinput "Choose a QVIS, NRRD, or PVM file"
set dicom dirinput "Choose a DICOM directory"

Example programs

Open a dataset and capture a screenshot

single-view.gscReproducible view
# Use the dataset UUID shown in BorgVR's information panel
opendataset "59DBB8EB-1674-4DAE-94D3-369E63D5A418"
waitloaded

rendermode lighting
setrotationquaternion 0 0 0 1
settranslation 0 0
setscale 1.15
clip 0 1 0 1 0 1
setlightdirection -0.4 0.5 0.75
waitframes 2
screenshot "single-view.png"

Complete command reference

Names in angle brackets are placeholders. Square brackets indicate an optional overload. Coordinates and colors are floating-point values; color components use the range 0 through 1.

Language and execution

SyntaxEffect
set <name> <value|expression|function>Assigns a literal, integer expression, or function return value to a variable.
unset <name>Removes a variable.
repeat <count> [as <name>]
endrepeat		Repeats a block, optionally with a zero-based counter.
if <condition>
else
endif		Runs a conditional block. else is optional.
noop <milliseconds>Waits for the specified time without blocking the app.
input <prompt>Opens a text field and returns the entered text. Use only with set.
fileinput <prompt>Opens a file picker and returns its path. Use only with set.
dirinput <prompt>Opens a directory picker and returns its path. Use only with set.

Logging and application

CommandEffect

logfile <file>Also writes subsequent log output to a file.
clearlogClears the configured log file.
logtimeLogs the current ISO 8601 timestamp.
logGPUInfo [bool]Logs Metal device information; the optional Boolean controls GPU-family output.
setdir <directory>Selects and creates the output directory used for relative paths.
screenshot [file]Saves the next completed rendered frame as a PNG.
resize <width> <height>Changes the BorgVR window content size in pixels.

Datasets, import, and export

CommandEffect
opendataset <dataset-uuid>Finds the dataset in the local and remote catalog, opens it, and waits for the renderer.
importfile <source> <destination> <description>Imports a QVIS, NRRD/NHDR, or PVM file as a BorgVR dataset.
importdirectory <source> <destination> <description>Imports a DICOM directory.
exportdataset <source.data> <destination.nrrd> <lod>Exports the selected LoD as an uncompressed NRRD; LoD 0 is full resolution.
setimportbricksize <int>Overrides the brick edge length for subsequent imports.
setimportoverlap <int>Overrides overlap for subsequent imports.
setbordermode <0|1|2>Sets border handling: 0 = zero fill, 1 = clamp, 2 = repeat.

Synchronization and performance

waitidle [empty-readbacks]Alias for waitloaded.
resetfpsResets performance statistics.
setfpswindow <seconds>Sets the measurement-window length for FPS statistics.
logfpsWaits for a complete measurement window and logs detailed FPS and paging values.
setDisplaySync <bool>Enables or disables render-output synchronization with the display.

Objects, markers, and measurements

Positions use normalized volume coordinates. Colors use RGB or RGBA in the range 0 through 1. Simple add... commands create new UUIDs; deterministic set... commands create or replace the supplied UUID and are suited to recorded scripts.

CommandEffect

hidemeasurements <bool>Locally hides or shows all measurements without deleting data.

savemarkers <file>Saves current markers and object instances.

clearmarkersRemoves all sphere and stroke markers, but not mesh instances.

Mesh instances and measurements

CommandArguments and effect
setmeshinstance <uuid> <asset-uuid> <name> <tx ty tz> <qx qy qz qw> <sx sy sz> <visible>Creates or replaces an instance of a known mesh asset using translation in meters, quaternion rotation, and scale.
setmeasurement <uuid> <length|area|volume> <name> <point-uuid x y z...>Creates or replaces a measurement. Every point consists of a UUID and XYZ position.
removemeasurement <uuid|name>Removes the first matching measurement.
clearmeasurementsRemoves all measurements.
Mesh dependency setmeshinstance references an asset by UUID. The asset must already be available locally or from a known server source. The command does not embed mesh data in the script.
