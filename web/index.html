Settings

When enabled, BorgVR stores partitions of the volume dataset, called bricks, in this browser's IndexedDB. Reusing cached bricks can reduce network traffic and may improve performance when the same parts of a volume are needed again. Browser storage is isolated by web origin, so other websites cannot read these cached bricks. They are still written to this computer's local storage, though, and another user of the same operating-system account could in principle inspect them. Turn this option off on public or shared computers when visualizing sensitive data.
